Ship plan

How I'd ship Cortex

The autonomy dial per segment, where it sits on the trust ladder, how it deploys, what it returns, and how I keep it safe.

01 · Dial

Autonomy per segment

- New eng lead ("Tesla driver") → Rung 3, Supervised; approves every draft and story batch.
- Seasoned PM ("Waymo passenger") → Rung 4, Bounded-autonomous, routine weekly update only; spot-checks.
- Exec stakeholder → Rung 2, Assisted; sees only PM-approved updates.
- The dial never moves the agent line. Targets only: today Cortex is at Rung 3 for everyone.
02 · Ladder

Rung + eval gate

- Current rung: 3, Supervised; nothing goes out until I approve.
- Gate to Rung 4: 4 consecutive weeks AND 30+ supervised runs.
- Thresholds: task completion ≥ 90% (no fact changes), tool-call accuracy ≥ 95%, 0 unsafe steps, jailbreak + missing-data replays 100%.
- Clean record: 0 trust incidents in the window.
- Status: gate not met yet; one run held for already-shipped stories, fixed with a prompt rule.
03 · Deploy

Where it runs & who owns it

- Runtime: serverless; scheduled for the Monday 08:00 cron, event-triggered for the Sev-1 hook.
- Owner: Varun Patel (PM); Northstar eng lead as infra escalation.
- Rollback: kill switch → git revert → remove a tool → drop the dial a rung.
- Monitoring: eval pass %, critic rejection rate, escalation rate, cost per run and per day, trust incidents.
04 · ROI

Value, not activity

- Outcome: ≥ 90% of updates approved with no fact changes.
- Time saved: ~45 min/week per project vs a shadow-mode baseline.
- Cost-to-serve: under 20 min per approved update (~$0.005 model + my review time).
- Trust incidents: 0 per 4-week window.
- Widen rule: up one notch, one segment only, after the gate holds 4 weeks + 30 runs; one incident drops it back.
05 · Governance

How I keep it safe

- Compliance: Orbit, Pulsar, customer PII and credentials never enter a prompt.
- Safety: posting, ship dates and story batches stay above the line at every setting; kill switch always on hand.
- Reliability: 8 steps, 120 s, $0.50/run, $2/day, 2 revisions, 10 stories; fail closed if the model is down.
- Next: seasoned PM to Rung 4, then a read-only Jira connector after 2 weeks in shadow mode.
Build insights

What I learned

The honest three: where it hurt, what clicked, and the moment something changed.

😵 Friction

The critic. It flip-flopped between Green and Yellow, failed correct drafts over wording, and held a good update for proposing stories that had already shipped. Each time the fix was in the rules I'd given it, not the model.

🧠 Learning

Capability is not permission. The strongest safety isn't a clever prompt but a missing tool: Cortex can't post because no post tool exists, which is why every jailbreak failed. Bounds that live outside the model held every time; prompt rules sometimes didn't.

💡 Aha

The same task passed at 17:05 and was held at 19:03. One good run proves nothing, so autonomy has to be earned with a number over a window, not given because a demo looked good.
